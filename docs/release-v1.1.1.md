# GridPilot v1.1.1

This patch release adds correctly sized local GridPilot brand assets for Home
Assistant and HACS: 256 px icons and logos plus 512 px high-density variants.

It also keeps the EV-battery card at the top of the EV charging section and
restores the derived 10/15/20% battery-curve thresholds on the home-battery card.

After installing, restart Home Assistant and refresh the HACS/frontend cache to
replace any previously cached placeholder icon.
